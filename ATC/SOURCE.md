# ATC/DDD Community Dataset

## Files
- original/WHO_ATC-DDD_2026-04-25.csv
- original/WHO_ATC-DDD-combinations_2026-04-25.csv

## Source
Community repository: https://github.com/fabkury/atcd
Release snapshot: April 25, 2026
Official underlying source: https://atcddd.fhi.no/atc_ddd_index/

## Contents
The main CSV contains the ATC hierarchy and available DDD,
unit-of-measure, administration-route and note fields.
The companion CSV contains combination-product DDD information.
